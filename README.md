# 🍽️ Daily Special Recipe Ideas

## 📖 Description
Daily Special Recipe Ideas is a simple recipe finder application that allows users to search for recipes by entering a food or main ingredient. The application uses TheMealDB API to retrieve and display up to five recipe suggestions, including meal names, images, and cooking instructions.

This project was created to practice working with APIs and dynamically displaying data using JavaScript.

## ✨ Features
- Search for recipes by food or main ingredient.
- Display up to five recipe suggestions.
- View recipe names and images.
- Read cooking instructions.

## 🛠️ Tech Stack
- **HTML5** – Structures the webpage and recipe sections.
- **CSS3** – Styles the webpage and recipe cards.
- **JavaScript** – Handles user input, API requests, and DOM updates.
- **TheMealDB API** – Provides recipe information, images, and cooking instructions.

## 🧠 What I Learned
- How to use JavaScript `fetch()` to retrieve API data.
- How to work with JSON responses.
- How to dynamically update the DOM.
- How to troubleshoot API errors and request limitations.
- How to research and integrate alternative APIs.

## 🚀 How to Use
1. Visit the [Live Website](https://restaurantapiproject1.netlify.app/).
2. Enter a food or main ingredient.
3. Click **Get Recipe**.
4. Browse the recipe suggestions and cooking instructions.

## 💻 How to Install
1. Clone the GitHub repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or with Live Server.
4. Enter an ingredient and click **Get Recipe** to search for recipes.
